AI Integration — Provider & Billing Policy

BRIDGE AI

BRIDGEのAI機能の用途・推奨プロバイダ・費用負担の方針をまとめたページです。営業議事録から社内AIチャットまで、どのAIをどう使うか、先方にご確認いただきたいことも整理しています。

① Where — Use Cases

BRIDGEのどこでAIを使うか

現在の仕様・タスクリストをもとに整理した、AI活用の場面一覧です。優先度の高いものから順に並んでいます。

② Structure — 2 Layers

AIは「音声→文字」と「文字→理解」の2段階

「どのAIを使うか」を考えるとき、BRIDGEのAIは性質の異なる2つのレイヤーに分かれます。プロバイダ選びはこの2つを別々に考えることが重要です。

【レイヤー 1 — 音声認識（STT: Speech to Text）】

  面談の音声 ────→  STT API  ────→  文字起こしテキスト
  録音データ          （Whisper 等）

  ※ Claude・Gemini等のLLMは「音声→文字」の変換機能を持っていない
  ※ 議事録機能を使う場合、STTプロバイダは必須（OpenAI Whisper が業界標準）

【レイヤー 2 — 大規模言語モデル（LLM）】

  文字起こしテキスト ─→  LLM API  ─→  要約・文章改善・合意抽出・チャット
  メモ・やり取りログ       （GPT / Claude 等）

つまり、「Claude だけで全部」は現時点では成立しません。Claude は LLM（レイヤー2）は得意ですが、STT（レイヤー1）の公式APIを持っていないため、議事録の文字起こしは別プロバイダが必要です。

推奨構成

A

標準案（推奨）— OpenAI 一本 推奨

音声認識（Whisper）も要約・文章改善・チャット（GPT-4o）もOpenAI一社で完結。APIキー1本・課金1箇所・運用がシンプル。BRIDGEのCSVタスク（議事録・メモ改善・チャット）の8割をこれで対応できます。最初の実装はこの構成を推奨します。

B

品質重視案 — Whisper（OpenAI）＋ Claude（Anthropic）後から追加可

音声認識はOpenAI Whisper、要約・合意抽出・文章改善はClaude。長いやり取りの合意抽出や丁寧な文章生成の品質を重視する場合の選択肢。最初からBで始める必要はなく、Aで実装後に合意抽出だけClaudeに切り替える形が現実的です。

C

Google寄せ — Gemini ＋ Google Speech 条件付き

Gmail・Googleカレンダーを本番でフル連携する先方でGoogleで統一したい場合のみ検討。CSVのAI要件だけで見るとGoogleを選ぶ積極的な理由は薄い。

⚠ Claudeだけでは議事録が完結しません
Claude は LLM（文章理解・生成）は強力ですが、面談の音声を文字に変換するSTT機能は持っていません。「全部Claude」にすると、文字起こしだけ別サービス（OpenAI Whisper・Google Speech等）が必要になり、結果的に2社以上になります。最初はOpenAI一本の方がシンプルです。
④ Billing — Who Pays?

AI利用料の費用負担とStripe対応

AI（文字起こし・要約など）は使った分だけ料金がかかる従量制です。面談の件数・時間・AIチャットの利用回数によって毎月の金額が変動します。費用の負担方法は次の2パターンから選択します。

A. 先方が直接AIを契約推奨

OpenAI等のアカウントを先方名義で作成し、APIキーをBRIDGEの設定画面に登録。AI利用料は先方からAI事業者へ直接お支払い。

BRIDGEは利用料を預からないため価格が透明。Stripe連携は不要。実装がシンプル。

B. BRIDGEが一括管理→月次請求複数テナント向け

BRIDGE側でAI費用をまとめ、利用量に応じて月々ご請求。この場合、Stripe Metered Billing（従量課金）の導入が必要。

「基本料金＋利用量に応じた変動分」の形で請求。

Stripe連携の必要性

パターンStripe（従量課金）必要な開発
A. 先方が直接契約 ✗ 不要 APIキー登録画面のみ（設定 > 会社情報）。現在の設定画面を拡張するだけ
B. BRIDGE一括→月次請求 ✅ 必要 利用量カウント（文字起こし時間・トークン数の記録）＋ Stripe Metered Billing ＋ Webhook ＋ 請求書連携の新規開発が必要 
【A. 先方が直接契約（推奨・シンプル）】

  先方 ──→ OpenAI（直接契約・直接支払い）
   │
   └──→ BRIDGEの設定画面にAPIキーを登録するだけ

【B. BRIDGE一括管理（複数テナント対応時）】

  ユーザーがAI機能を使う
   │
   └──→ BRIDGE がトークン数・秒数をカウント
            │
            └──→ Stripe Metered Billing
                     │
                     └──→ 月次で先方に自動請求
💡 推奨の進め方
まずA（先方直契約）でローンチし、複数テナントに展開して「使った分だけ自動請求」が必要になった段階でB＋Stripeを検討。最初からStripe従量課金を作り込むとリリースが重くなります。

議事録 / 文章改善 / やり取り合意抽出 / AIチャット / 顧客入力補助		 実装優先順位・必要なプロバイダが決まるため

⑥ Cost — Rough Estimate

AI利用コストの目安

OpenAI（Whisper + GPT-4o）を使った場合の概算です。利用量・プランによって変動します。

機能課金単位目安
議事録（Whisper） 音声1分あたり約$0.006 1時間の面談 ≒ 約50〜60円。月10件なら数百円〜
要約・文章改善（GPT-4o） トークン数に比例 1件の要約 ≒ 数円〜十数円。利用頻度で変動
やり取り合意抽出 トークン数（ログが長いほど増加） 長いやり取りは1件あたり数十円になる場合あり
AIチャット メッセージ数・長さに比例 軽い質問なら1件数円以下
💡 月額コストのイメージ
営業5人、月20件の面談（各1時間）、議事録＋要約＋軽いチャット利用の場合、月数千円〜1万円台が目安です。利用量が少なければもっと安く、やり取りログが大量なら増えます。正確な見積もりは月間の面談本数と人数を教えていただければ算出できます。
