# 利用ガイドの更新

## 構成

- `index.html`：目的・役割から読む入口
- `guide.html`：21章の操作説明、画面例、図解
- `features.html`：機能分類、未解消事項、原本項目の検索
- `handover.html`：引継ぎチェック、サービス構成、費用試算
- `guide-content.json`：操作説明の編集元
- `requirements.json`：原本の項目・結果の参照用データ
- `manual.css` / `manual.js`：表示・検索・試算・ローカルチェック保存

HTMLは生成物です。編集元を修正して `python3 docs/build-manual.py` を実行してください。外部ライブラリ・DB・ビルドサービスへの接続なしで生成できます。仕様書から業務アプリのデータは変更しません。

## 更新時の確認

1. 原本を読み直し、操作・廃止・保留・最新の不具合の記録を確認する。
2. 原本の結果と実装状況を分ける。特に最終確認No.106は元のチェック内容と備考の指摘が異なるため、備考を含めて確認する。
3. 画面名・メニュー・ボタン・権限を現行画面と照合する。
4. 料金は公式価格と利用中の契約を区別し、確認日・想定為替・除外費用を更新する。
5. HTMLを再生成し、ローカルサーバーでPC・モバイル・リンク・検索・空結果・費用計算・チェック保持・印刷を確認する。
6. 公開前に個人情報・認証情報・未承認の機密事項がないか確認する。

確認用サーバー：`python3 -m http.server 4173 --bind 127.0.0.1 --directory docs`
