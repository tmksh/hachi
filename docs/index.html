BRIDGE
統合業務支援システム

建設業・リフォーム業向けに設計されたオールインワン業務管理プラットフォーム。顧客管理・工事管理・勤怠・ワークフロー・マーケティングを一つのシステムで管理します。

機能一覧を見る GitHub
Overview

システム概要

BRIDGEは建設業・リフォーム業の現場と経営をひとつのプラットフォームで繋ぎます。受注から施工完了まで、すべての業務フローをカバーします。

Architecture

システムアーキテクチャ

3層構成。クライアント・サーバー・データ層が明確に分離されており、エッジでのロール保護とリアルタイム通信を実現しています。

クライアント層
Next.js App Router + React 19
ブラウザ上で動作するフロントエンドアプリケーション。サーバーコンポーネントとクライアントコンポーネントを組み合わせ、初回表示速度と操作性を両立します。Tailwind CSS + Shadcn/UI によるニューモーフィズムデザイン。
ダッシュボード CRM / 商談 工事管理 勤怠 ワークフロー マーケティング 設定
HTTPS / Supabase JS Client (REST + WebSocket)
サーバー・エッジ層
Next.js Middleware + Server Actions（Netlify Edge）
Netlify のエッジネットワーク上でミドルウェアが実行されます。すべてのページリクエストに対して認証チェックとロールベースのルート保護を行い、権限のないユーザーを /unauthorized にリダイレクトします。
middleware.ts（RBAC） Server Actions セッション更新 ルート保護
PostgreSQL クエリ / REST API / WebSocket (Realtime)
Database
Supabase DB
PostgreSQL 15。RLS（行レベルセキュリティ）で company_id ごとにデータを分離
Auth
Supabase Auth
メール＋パスワード認証。JWT トークンをブラウザの Cookie に保存
Storage
Supabase Storage
文書・クリエイティブファイルのクラウド保存。RLS で会社ごとに分離
Realtime
Supabase Realtime
WebSocket による通知・勤怠状態のリアルタイム配信

マーケティング施策
全テーブルに company_id カラムを設け、RLS（Row Level Security）ポリシーを適用しています。ログインユーザーのトークンから company_id を取得し、自社データのみ参照・更新できます。異なる会社のデータは一切アクセスできません。
Access Control

認証・ロール設計

4段階のロール体系でページアクセス・メニュー表示・データ閲覧を制御します。ミドルウェアとデータベース両方でアクセス制御を二重に実施しています。

ロール階層図
オーナー owner
全機能・全データにフルアクセス。予算管理・マーケティングを含む最上位権限。会社の代表者が使用します。
本部管理者 hq_admin
オーナーとほぼ同等の権限。予算管理・マーケティングへのアクセスも可能。本社スタッフが使用します。
施工店管理者 contractor_admin
CRM・工事・請求管理にアクセス可能。予算管理・マーケティングは閲覧不可。施工店の責任者が使用します。
社員 employee
勤怠・ワークフロー・回覧・カレンダー・文書などポータル機能のみ利用可能。一般スタッフが使用します。

Feature Detail

リード〜受注フロー

問い合わせから受注・工事着工までの一連の流れをシステムが連携してサポートします。各ステップで次のアクションへワンクリックで遷移できます。

ステップフロー
Step 1
顧客登録
顧客管理（/crm）から新規顧客を登録。氏名・連絡先・予算感・担当者を入力。
▶
Step 2
商談追加
パイプライン（/deals）の「＋商談追加」ボタンから顧客を選択して商談を作成。ステージ・金額・クロージング日を設定。
▶
Step 3
見積作成
商談カードの「見積を作成」ボタン（見積提出ステージ以降で表示）から見積新規作成へ。顧客・金額が自動引き継ぎ。
▶
Step 4
受注確定
商談カードを「受注」ステージにドラッグすると受注ダイアログが表示。次のアクション（見積 or 工事）を選択。
▶
Step 5
工事登録
工事管理（/constructions）で工事を登録。顧客・受注額が引き継がれた状態で新規作成フォームが開く。
パイプライン操作ガイド
操作場所説明
商談を追加 パイプライン右上 「＋商談追加」ボタン → 顧客選択・商談名・金額・ステージを入力してDB保存
ステージを変更 カンバン上 商談カードをドラッグ&ドロップで別ステージへ移動。自動でDBを更新
見積を作成 商談カード内 「見積提出」以降のステージで商談カード下部に表示されるボタン。顧客・金額を引き継いで見積新規作成ページへ遷移
受注確定 カンバン上 「受注」ステージへドラッグすると受注ダイアログが表示。見積作成・工事登録のどちらかを選択して次へ進める

Feature Detail

工事原価管理表

工事詳細ページ「原価」タブに搭載。1工事につき複数の下請け業者ごとに予算・発注・月次請求を管理し、粗利をリアルタイムで把握できます。

何ができるか
Input
数値を直接入力
白いセルをクリックするだけで編集開始。業者名・工種・予算額・発注額・月次請求を入力できます。
Auto Calc
緑セルは自動計算
実行予算合計・確定額・予算残・請求残・工事粗利額・粗利率がリアルタイムで自動更新されます。
Alert
赤字でアラート
予算残がマイナスになると赤く表示。請求残（未回収）も赤字で一目でわかります。
列の構成
グループ 列名 種別 内容・説明
基本情報 発注ステータス 入力 クリックで「発注済 ↔ 未発注」を切り替え
施工業者名 入力 下請け業者・職人の名称
工種 入力 外構工事・電気工事・塗装工事など
管理用予算 入力 社内管理用の上限予算（対外的な実行予算とは別管理）
実行予算・
追加契約		 実行予算 入力 当初の発注予定金額
追加契約①② 入力 設計変更・追加工事が発生した場合の増額分
追加含む実行予算 自動 実行予算 + 追加契約① + 追加契約②
発注 発注額 入力 実際に発注した金額
追加発注①②③ 入力 工事中に発生した追加発注
確定額 自動 発注額 + 追加発注① + 追加発注② + 追加発注③
予算残 自動 追加含む実行予算 − 確定額（マイナスで赤字）
〇月請求（12ヶ月） 入力 業者から届いた月次請求書の金額を月ごとに入力
請求管理 請求残 自動 確定額 − 月次請求の合計（未払いがあると赤字）
サマリーの計算式
実行予算ベース（暫定）
工事粗利額 = 契約金額 − 実行予算合計
工事粗利率 = 工事粗利額 ÷ 契約金額 × 100
発注確定前の見込み値。計画段階で利益を確認するために使います。
確定額ベース（実績）
工事粗利額 = 契約金額 − 確定額合計
工事粗利率 = 工事粗利額 ÷ 契約金額 × 100
実際に発注した金額ベースの粗利。工事が進むにつれて精度が上がります。
操作方法
操作方法
数値を入力する白いセルをクリック → キーボードで入力 → Enter または別セルへ移動で確定
発注ステータスを変える「発注済」「未発注」バッジをクリックするたびに切り替わります
業者行を追加する表の下部「+ 行を追加」をクリック
業者行を削除する対象行にホバー → 右端のゴミ箱ボタンをクリック
保存する右上「保存する」ボタンをクリック（緑の「保存済み」に変わります）
Screenshots

画面スクリーンショット

実際のシステム画面の一部です。

ダッシュボード
受注額・パイプライン・顧客数・進行件数などのKPIをウィジェット形式で一覧表示。勤怠打刻・ワークフロー状況・未読お知らせも確認できます。
勤怠管理
ワンクリックで出退勤打刻。アナログ時計UIでリアルタイム表示。管理者は全スタッフの勤怠確認・承認・月次レポートに対応しています。
ワークフロー
経費申請・休暇申請・購入申請を電子化。申請から承認フロー・完了まで、ステータスをリアルタイムで管理できます。
設定・プロフィール
プロフィール編集・通知設定・会社情報の管理。通知設定は Supabase に永続保存されます。
アクセス制限ページ
権限のないページにアクセスした場合に表示されます。ミドルウェアによるロールベースのルート保護（RBAC）を実装済みです。
