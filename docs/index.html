BRIDGE
統合業務支援システム

建設業・リフォーム業向けに設計されたオールインワン業務管理プラットフォーム。顧客管理・7タブ構成の工事管理・勤怠・ワークフロー・文書管理を一つのシステムで管理します。各加盟店は {slug}.bridge-linq.com の専用 URL で利用します。マーケティング機能は v2 非公開（ルートブロック）です。

Overview

システム概要

BRIDGEは建設業・リフォーム業の現場と経営をひとつのプラットフォームで繋ぎます。受注から施工完了まで、すべての業務フローをカバーします。

Architecture

システムアーキテクチャ

3層構成。クライアント・サーバー・データ層が明確に分離されており、エッジでのロール保護とリアルタイム通信を実現しています。

クライアント層
Next.js App Router + React 19
ブラウザ上で動作するフロントエンドアプリケーション。サーバーコンポーネントとクライアントコンポーネントを組み合わせ、初回表示速度と操作性を両立します。Tailwind CSS + Shadcn/UI によるニューモーフィズムデザイン。
ダッシュボード CRM / 商談 工事管理 勤怠 ワークフロー クラウドサイン連携 設定
HTTPS / Supabase JS Client (REST + WebSocket)
サーバー・エッジ層
Next.js Middleware + Server Actions（Netlify Edge）
Netlify のエッジネットワーク上でミドルウェアが実行されます。認証チェック・ロールベースのルート保護に加え、サブドメイン（slug）からテナント（company_id）を解決します。権限のないユーザーを /unauthorized にリダイレクトします。
middleware.ts（RBAC） サブドメイン解決 Server Actions Netlify API（ドメイン自動追加） セッション更新 ルート保護

Access Control

認証・ロール設計

3段階のロール体系でページアクセス・メニュー表示・データ閲覧を制御します。2026/04/16 設計レビューによりオーナーロール（owner）は廃止され、最上位は本部管理者（hq_admin）です。ミドルウェアとデータベース両方でアクセス制御を二重に実施しています。

ロール階層図
本部管理者 hq_admin
最上位権限。予算管理・BI・全 CRM/工事機能・会社設定（CloudSign 連携含む）・メンバー管理にアクセス可能。本社スタッフが使用します。
施工店管理者 contractor_admin
CRM・工事・請求管理にアクセス可能。予算管理は閲覧不可。施工店の責任者が使用します。
社員 employee
勤怠・ワークフロー・回覧・カレンダー・文書などポータル機能のみ利用可能。一般スタッフが使用します。

Feature Detail

リード〜受注フロー

問い合わせから受注・工事着工までの一連の流れをシステムが連携してサポートします。各ステップで次のアクションへワンクリックで遷移できます。

ステップフロー
Step 1
顧客登録
顧客管理（/crm）から新規顧客を登録。氏名・連絡先・予算感・担当者を入力。
▶
Step 2
商談追加
パイプライン（/deals）の「＋商談追加」ボタンから顧客を選択して商談を作成。ステージ・金額・クロージング日を設定。
▶
Step 3
見積作成
商談カードの「見積を作成」ボタン（見積提出ステージ以降で表示）から見積新規作成へ。顧客・金額が自動引き継ぎ。
▶
Step 4
受注確定
商談カードを「受注」ステージにドラッグすると受注ダイアログが表示。次のアクション（見積 or 工事）を選択。
▶
Step 5
工事登録
工事管理（/constructions）で工事を登録。顧客・受注額が引き継がれた状態で新規作成フォームが開く。
パイプライン操作ガイド

ステージを変更 カンバン上 商談カードをドラッグ&ドロップで別ステージへ移動。自動でDBを更新

Feature Detail

工事管理（7タブ構成）

工事詳細ページ（/constructions/[id]）は 2026/04/16 設計レビューに基づき、旧5タブから7タブに再構成されています。受注から完工・請求までを1画面で完結できます。

タブ一覧
タブキー機能概要
工程表 schedule ガントチャートで工程タスクの期間・進捗を管理。タスクの追加・編集・期間変更に対応。
見積もり estimate 1工事に複数見積を保持。版（version）管理・改訂（parent_estimate_id）に対応。予備費1（デフォルト2%）・予備費2（3%）・デフォルト粗利率（50%）を見積ごとに設定可能。
契約書 contract 契約書 PDF のアップロード・管理。顧客・工期・契約金額をコンテキストとして表示。
追加変更 change 追加変更工事（change_orders）の作成・承認。変更前後の明細・差額を記録。CloudSign B案：会社設定で API キーを登録済みの場合は電子署名送信、未設定時は PDF ダウンロードで代替。
工事台帳 budget 原価管理表（実行予算・発注・月次請求・粗利）。construction_cost_budgets テーブルへ永続化。詳細は下記「工事台帳」セクション参照。
発注書 orders 下請発注（contractor_orders）の作成・ステータス管理。支払回数は 2回 / 4回 / 6回 / 12回 から選択し、着工時・中間・追加・完了のフェーズに按分（payment_schedule JSONB）。
請求書 invoices 工事に紐づく請求書一覧。単発作成に加え、会社設定の締日（20日締め / 月末締め）に基づく月次請求の一括生成に対応。
関連設定
CloudSign 連携（設定 > 会社情報）
companies.settings.cloudsign に enabled / api_key を保存。追加変更タブから書類送信。顧客が別途 CloudSign 契約する B案。
請求締日（設定 > 会社情報）
invoice_closing_day（20 または月末）で月次請求の計上期間・支払条件を決定。工期に基づき未生成の月次請求を自動作成。
Feature Detail

工事台帳（原価管理表）

工事詳細ページ「工事台帳」タブに搭載。1工事につき複数の下請け業者ごとに予算・発注・月次請求を管理し、粗利をリアルタイムで把握できます。入力データは construction_cost_budgets テーブルに永続化され、リロード後も保持されます。

何ができるか
Input
数値を直接入力
白いセルをクリックするだけで編集開始。業者名・工種・予算額・発注額・月次請求を入力できます。
Auto Calc
緑セルは自動計算
実行予算合計・確定額・予算残・請求残・工事粗利額・粗利率がリアルタイムで自動更新されます。
Alert
赤字でアラート
予算残がマイナスになると赤く表示。請求残（未回収）も赤字で一目でわかります。
列の構成
グループ 列名 種別 内容・説明
基本情報 発注ステータス 入力 クリックで「発注済 ↔ 未発注」を切り替え
施工業者名 入力 下請け業者・職人の名称
工種 入力 外構工事・電気工事・塗装工事など
管理用予算 入力 社内管理用の上限予算（対外的な実行予算とは別管理）
実行予算・
追加契約		 実行予算 入力 当初の発注予定金額
追加契約①② 入力 設計変更・追加工事が発生した場合の増額分
追加含む実行予算 自動 実行予算 + 追加契約① + 追加契約②
発注 発注額 入力 実際に発注した金額
追加発注①②③ 入力 工事中に発生した追加発注

請求管理 請求残 自動 確定額 − 月次請求の合計（未払いがあると赤字）
サマリーの計算式
実行予算ベース（暫定）
工事粗利額 = 契約金額 − 実行予算合計
工事粗利率 = 工事粗利額 ÷ 契約金額 × 100
発注確定前の見込み値。計画段階で利益を確認するために使います。
確定額ベース（実績）
工事粗利額 = 契約金額 − 確定額合計
工事粗利率 = 工事粗利額 ÷ 契約金額 × 100
実際に発注した金額ベースの粗利。工事が進むにつれて精度が上がります。

Screenshots

画面スクリーンショット

実際のシステム画面の一部です。

ダッシュボード
受注額・パイプライン・顧客数・進行件数などのKPIをウィジェット形式で一覧表示。勤怠打刻・ワークフロー状況・未読お知らせも確認できます。
勤怠管理
ワンクリックで出退勤打刻。アナログ時計UIでリアルタイム表示。管理者は全スタッフの勤怠確認・承認・月次レポートに対応しています。
ワークフロー
経費申請・休暇申請・購入申請を電子化。申請から承認フロー・完了まで、ステータスをリアルタイムで管理できます。
設定・プロフィール
プロフィール編集・通知設定・会社情報の管理。通知設定は Supabase に永続保存されます。
アクセス制限ページ
権限のないページにアクセスした場合に表示されます。ミドルウェアによるロールベースのルート保護（RBAC）を実装済みです。
