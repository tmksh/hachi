Getting Started

はじめに｜ログインと画面の見方

初めて使う方向けに、ログインから基本画面までを説明します。

ログイン手順
  1. ブラウザで自社専用 URL（https://{自社slug}.bridge-linq.com）を開きます。slug が未発行の場合は運営にお問い合わせください。
  2. メールアドレスとパスワードを入力して「ログイン」をクリックします。
  3. ログインに成功するとダッシュボードが表示されます。パスワードを忘れた場合はログイン画面の「パスワードをお忘れですか？」から再設定できます。

画面の基本構成

  • 左サイドバー：大項目（ダッシュボード／リード／生産／ポータル）。クリックで展開してページ移動します。表示される項目はロール・権限設定によって変わります。
  • サイドバー下部：グローバル検索・通知ベル・社内チャット・BRIDGE AI。
  • 右下 BRIDGE AI：どの画面からでも AI チャットを起動でき、開いている画面の内容を踏まえて回答します。
  • ユーザーメニュー（左下アイコン）：プロフィール／設定（/settings）・外部連携（/settings?tab=external_integrations）・ログアウト。
検証用アカウントは本ページ下部「ログイン情報」を参照してください。

Feature Specs

機能詳細（大項目 → 画面仕様と使い方）

各メニューで「何ができて、どう操作するか」を実画面のキャプチャ付きで説明します。実装の正本は apps/web です。

ダッシュボード › /dashboard
ダッシュボード

ログイン後の個人ハブ。ウィジェットの表示・順序・サイズをユーザー単位で保存し、日々の業務導線を集約します。

使い方
  1. 上部の KPI カード（受注額・パイプライン・顧客数・商談数・未入金・承認待ちなど）で今月の状況を確認します。
  2. 勤怠打刻ウィジェットの「出勤」「退勤」ボタンでその場で打刻できます。
  3. 右上の「表示設定」からウィジェットの表示／非表示を切り替えます。
  4. ウィジェットはドラッグ＆ドロップで並べ替え、サイズ変更も可能。レイアウトは自動保存されます。
  5. 期限切れ ToDo がある場合は上部にアラートバーが表示されます。「確認する」から今日のフォーカスへ移動します。

主なウィジェット

  • AIフォーカス / 勤怠 / お知らせ / ワークフロー
  • KPI：受注額・パイプライン・顧客数・進行案件・商談数・未入金・承認待ち・進行中契約
  • 一覧系：売上トレンド・商談パイプライン・最近の見積／顧客・生産サマリー・進行中工事
  • 未フォローアップ（デフォルト非表示）
保存先は localStorage（dashboard-widgets-v1）と DB のダッシュボード設定の併用。ウィジェット設定の参照先は 入力 → 参照（ポータル）。
ダッシュボード › /bi（実験UI: /bi2）
BIダッシュボード

経営層向けの売上・粗利・着地予測。顧客の見込度 A/B/C と会社別確度%から期待値売上を算出します。

使い方
  1. 右上の年度セレクタで対象年度を選択します（会計開始月は設定 › 会社情報）。
  2. 初回は「期首設定」から年間目標・製造間接費・販管費・部門別目標を入力します。
  3. 「いま、会社にいくら残る？」で売上 → 粗利 → 固定費 → 営業利益（最終のもうけ）の流れを確認します。
  4. 部門別カードで各部門の目標達成率・昨対を確認。カードはドラッグで並べ替えできます。
  5. 見込度 A/B/C の確度%（既定 A80/B50/C20）は設定 › 会社情報で調整でき、期待値売上に反映されます。
  6. 右のパネルから BRIDGE AI に「どうしたら良くなるか相談する」ことができます。

主要指標

  • 売上／粗利／売上総利益（粗利−製造間接費）／営業利益（−販管費）
  • 目標達成・昨対比・着地ティア（契約済・A見込含など）・部門別・見込度別
  • 予備費バナー（決算戻し）・期首設定ダイアログ

設定項目（BI設定パネル）

  • 製造間接費・販管費予算、期中変更ログ、部門別目標
  • 予備費率（権限キー reserve_fee）、実績ソース／着地ティアのフィルタ
  • 粗利率フォールバック、全社間接費按分（equal / revenue_share）
関連テーブル: bi_company_config / bi_annual_settings / bi_budget_change_log / bi_overhead_items / bi_department_targets。/bi2 は同系統メトリクスのカードUI（DnD・ナビ非掲載）。会計開始月は会社情報。初回 SSR は既定4月始まりで描画し、クライアント再取得後に会社設定へ揃います。決算書（/financials）の確定値は経営層向けに BI から参照できます。期首・見込度・実績ソースの全項目は 入力 → 参照（BI）。
リード › /leads
問い合わせ管理

顧客化する前の問い合わせを一覧管理します。Web フォーム等は Webhook、電話・店頭は手動登録です。CRM への転記は「顧客化」ボタンが必要です（自動顧客化はしません）。

使い方
  1. 「手動登録」で氏名・経路（電話／手動／Web／メール／Instagram／その他）・内容を入力します。
  2. 外部サイトからは Webhook URL とシークレット（ヘッダー X-Bridge-Secret）で取り込みます。有効化・再発行・無効化・テスト取り込みができます。
  3. 未対応／対応中の行から「顧客化」すると CRM 顧客が作成され、以後は「顧客を開く」で遷移します。「見送り」もできます。

リード › /crm
顧客・商談管理

顧客マスタと商談カンバンを一体化。旧 /deals は /crm?view=pipeline へリダイレクトします。

使い方（顧客の登録〜商談の進行）
  1. 右上の「新規顧客」から法人／個人を選んで登録します。担当者・獲得ソース・タグも設定できます（商談はパイプラインの「商談を追加」から）。
  2. 検索ボックスとフィルタで絞り込み、右上の切替で一覧／カード／パイプラインビューを変更できます。
  3. 顧客の行（カード）をクリックすると顧客詳細（7タブ）が開きます。
  4. 「記入画面」タブで見込度 A/B/C や特需を設定すると BI の期待値売上に反映されます。
  5. パイプラインビューでは商談カードをドラッグ＆ドロップでステージ移動。「受注」へ移動すると受注確定ダイアログが開き、見積作成 or 工事登録へ進めます。

詳細操作ガイド（タブごとの使い方）

記入画面 — 顧客情報の入力・編集/crm/[id] › 記入画面
  1. 顧客詳細の「記入画面」タブを開きます。主な項目：電話番号（携帯）・メール・EIGHT-ID・契約者氏名（必須）・法人／個人・会社名・部門・年齢・住所・知ったきっかけ・問い合わせ分類／日・担当者・予算感（上限／下限）・問い合わせ内容・特需・独自確度%・見込度 A/B/C・ステータス・タグ・備考・LINE/Slack ID。
  2. 定型項目にない情報は「項目を追加」で独自項目を作成できます（AI による項目提案あり）。
  3. 入力後、下部の「保存」（新規登録時は「登録」）をクリックすると「保存しました」と表示されます。
見込度 A/B/C と特需・独自確度%は BI ダッシュボードの期待値売上に反映されます。
商談 — 要約メモと AI ステージ提案/crm/[id] › 商談
  1. 商談タイムラインで活動履歴を確認し、商談要約のテキスト欄にメモを入力して「要約を保存」をクリックします。
  2. 要約テキストをドラッグ選択すると、その内容から ToDo を追加できます。
  3. AI がステージ・見込度の変更を提案した場合は、提案カードの適用ボタンで反映できます。
録音・要約 — 商談録音と文字起こし/crm/[id] › 録音・要約
  1. 「録音開始」をクリックすると録音中パネルが表示されます（マイク許可が必要）。
  2. 商談終了後に「録音停止」をクリックすると、音声がアップロードされ自動で文字起こし・要約が実行されます（voice_jobs）。
  3. 生成された要約は編集でき、「保存」で確定します。「顧客メールへ送信」にチェックすると要約をそのままメール送付できます。
  4. 処理に失敗した場合は「リセット」でやり直せます。
ToDo — タスクの追加・完了/crm/[id] › ToDo
  1. 一覧右上の「新規」をクリックし、タイトル・期限日・メモを入力して「追加」を押します（「ToDoを追加しました」と表示）。
  2. 各 ToDo のチェックボックスで完了／未完了を切り替えます。Today / Upcoming / All の3カラムで期限別に確認できます。
スケジューリング — 面談候補日の提案と確定/crm/[id] › スケジューリング
  1. 面談区分（対面／オンライン／電話）、希望時間帯、所要時間を選択します。
  2. 「候補日を提案」または「AIで最適化」をクリックすると、カレンダーの空きから候補日が生成されます。
  3. 候補ごとの「この日時で確定 → カレンダー登録」で予定として登録します。
  4. 「候補日の案内メール文面を生成」→「顧客にメール送信」で、候補日を顧客へ案内できます。最後に「この内容で保存」で確定します。
ドキュメント一覧 — ファイルのアップロード/crm/[id] › ドキュメント一覧
  1. 「アップロード」をクリックすると「文書をアップロード」ダイアログが開きます。
  2. 文書名（必須）・カテゴリを入力し、ファイル（必須）を選択して「アップロード」を押します。
  3. アップロードしたファイルは一覧から閲覧・ダウンロードできます。

リード › /quotes
見積管理

見積の作成・版管理・粗利監視・PDF 出力。工事詳細／契約詳細からも紐付け可能です。

使い方（見積の作成〜発行）
  1. 一覧右上の「新規見積」をクリックし、「見積を作成」ダイアログで顧客名を検索・選択します（商談カードの「見積を作成」からも顧客を引き継いで開けます）。
  2. 作成画面で件名（必須）を入力し、「大項目を追加」→各大項目の「詳細追加」で明細行（詳細項目・数量・単位・原価・単価）を入力します。粗利・粗利率は自動計算されます。
  3. ヘッダーの「保存」で見積が作成され、詳細画面へ移動します。
  4. 詳細画面で予備費（会社確保分）／予備予備費（現場対応分）を金額入力します（未計上の場合は警告表示）。
  5. 「PDFプレビュー」メニューから見積書（顧客向け）／原価内訳書（社内・予備費含む）を確認し、印刷／PDF保存します。
  6. 粗利率が会社基準以上なら「確定する」、下回る場合は「上司への承認申請」からワークフロー承認を取ります（下記の詳細操作ガイド参照）。

詳細操作ガイド

明細の編集 — 大項目と詳細行/quotes/new・/quotes/[id]
  1. 「大項目を追加」で工事区分などのカテゴリ（例：仮設工事・木工事）を作ります。
  2. 大項目内の「詳細追加」で行を追加し、詳細項目・数量・単位・原価・単価を入力します。金額＝数量×単価、粗利＝売価−原価が自動計算されます。
  3. 行・大項目は削除アイコンで削除できます。改訂はコピー作成（版管理）で新版を作成します（version / parent で世代管理）。
予備費の設定/quotes/[id]（詳細画面）
  1. 見積詳細のサマリー付近にある「予備費（会社確保分）」「予備予備費（現場対応分）」の入力欄に金額を入力します。
  2. 入力欄からフォーカスを外す（別の場所をクリックする）と自動で更新されます。
  3. 予備費は原価内訳書（社内向けPDF）にのみ表示され、顧客向け見積書には出ません。
新規作成画面（/quotes/new）には予備費欄はありません。保存後の詳細画面で設定してください。
粗利ゲート — 上長承認の申請/quotes/[id]（詳細画面）
  1. 粗利率が会社基準（既定 50%＋予備費 10%）を下回ると、確定ボタンの代わりに「上司への承認申請」が表示されます。
  2. クリックすると「見積の上長承認申請」ダイアログが開きます。申請コメント（粗利率低下の理由・必須）と承認者（必須）を選択します。
  3. 「申請する」を押すと「上長への承認申請を送信しました」と表示され、承認者のワークフロー画面に届きます。承認待ちの間は WF 詳細へのリンクが表示されます。

使い方（管理者の初期セットアップ）

  4. マスタ › CRMマスタで商談ステージ・失注理由・獲得ソース・タグを自社の運用に合わせて編集します。

詳細操作ガイド（サブメニューごとの使い方）

プロフィール — 表示名・連絡先の編集概要 › プロフィール
  1. 「プロフィール」カードで表示名・電話・部署・役職を編集します（メールアドレスと権限はここでは変更不可）。
  2. 文字サイズ（小／中／大）は選択すると即時に画面へ反映されます。
  3. 右下の「保存」をクリックすると「プロフィールを更新しました」と表示されます。
本部管理者は同タブ下部の「会社情報」カードで会社名・代表者名・インボイス登録番号・住所・請求締日（月末締め／20日締め）・始業／終業時刻・会計年度の始まり月・見込度A/B/C%・特需デフォルト契約率・クラウドサイン連携・全銀振込元を編集し、「会社情報を保存」で確定します。始業／終業は組織 › 勤怠設定と同じ attendance_settings です。
セキュリティ — パスワード変更概要 › セキュリティ
  1. 「パスワード変更」カードで新しいパスワード（6文字以上）と確認用を入力します（不一致の場合はボタンが無効になり「パスワードが一致しません」と表示）。
  2. 「パスワードを変更」をクリックすると「パスワードを変更しました」と表示されます。
Google ログインを使用している場合、パスワード変更は不要です。
通知設定 — 通知の ON/OFF概要 › 通知設定
  • トグルは4種類：メール通知／プッシュ通知／承認リマインダー／日報リマインダー。
  • スイッチを切り替えると即時保存され、「{項目名}を有効／無効にしました」と表示されます（保存ボタンはありません）。いまは設定の記憶だけで、実際のメール通知やリマインダーにはまだつながっていません。
メール署名 — 署名テンプレートの登録概要 › メール署名
  1. 「署名」欄に会社名・氏名・連絡先などを入力します。
  2. 「署名を保存」をクリックすると「署名を保存しました」と表示され、以後メール作成時に本文末尾へ自動挿入されます。
PDF編集 — 契約書テンプレートの作成・編集（管理者）概要 › PDF編集 → /settings/pdf-builder

テンプレート一覧：「契約書テンプレート」の「新規テンプレート」で新規作成、既存カードの鉛筆アイコンで編集、ゴミ箱アイコン→「削除する」で削除します。

編集画面の手順：

  1. 未インポートの場合、中央の「PDFをインポートする」をクリック（またはドラッグ＆ドロップ）して、ベースになる PDF（最大10MB）を読み込みます。
  2. ヘッダーでテンプレート名と文書種別を設定します。
  3. 左パレットの項目をクリックして追加します。自動入力項目（顧客名・顧客住所・工事名・工事番号・受注金額（税抜／税込）・工期開始／終了・本日日付）は契約・工事データから埋まります。税込欄は税抜想定値×1.1 です（元データが税込だと二重加算）。乙（自社名・住所）の binding はありません（組み込み契約テンプレート側で乙を補完）。自由項目（テキスト入力・テキストエリア・チェックボックス・署名・固定テキスト）は作成時に入力する欄になります。
  4. 追加したフィールドは PDF 上でドラッグして位置調整、右下ハンドルでサイズ変更します。右サイドパネルでラベル・データ連携・文字サイズを設定できます。
  5. 右上の「保存」をクリックすると「保存しました」と表示され、一覧に戻ります。作成したテンプレートは契約詳細の「書類作成」タブで選択できます。
メンバー管理 — 招待・ロール変更・削除（管理者）組織 › メンバー管理
  1. 招待：右上の「メンバー追加」→「メンバーを招待」ダイアログで表示名・メールアドレス・ロール（すべて必須）を入力し、「招待メールを送信」をクリックします。送信後は「招待リンクをコピー」で URL 共有、「続けて招待する」で連続登録もできます。
  2. ロール変更：一覧の各行にあるロールのプルダウンを変更すると即時反映されます（「ロールを変更しました」）。ロール：本部管理者／施工店管理者／社員／管理者／経営層／営業／現場担当／設計士／総務／外部協力業者。
  3. 再送：送信アイコン →「再送信する」で招待メールを再送します。
  4. 削除：ゴミ箱アイコン →「メンバーを削除しますか？」→「削除する」で削除します。
ロール・権限設定 — 機能アクセスのマトリクス（管理者）組織 › メンバー管理（画面下部）
  1. メンバー管理画面の下部にある「ロール・権限設定」マトリクスを表示します（ロール×機能の表）。
  2. セルをクリックすると ✓（許可）／—（不可）が切り替わります。
  3. 独自ロールが必要な場合は「ロールを追加」→「カスタムロールを追加」でロール名（必須）・ベースロール・カラーを設定して「追加」を押します。
  4. 最後に「権限を保存」をクリックすると「ロール・権限設定を保存しました」と表示され、サイドバーの表示項目に反映されます。
機能キーはサイドバー各項目＋ settings_* ＋ reserve_fee（BI の予備費表示）。未設定の会社はデフォルトのロール表が適用されます。
勤怠設定 — 就業時間と休暇区分（管理者）組織 › 勤怠設定（会社情報の始業／終業と共通）
  1. 就業時間：始業時刻・終業時刻・休憩時間（分）を入力すると所定労働時間が表示されます。
  2. 休暇区分：入力欄に区分名（例：慶弔休暇）を入れて「追加」、チップの×で削除します。ここで登録した区分が勤怠画面の勤務区分プルダウンに表示されます。
  3. 「保存」をクリックすると「勤怠設定を保存しました」と表示されます。
ワークフロー — 申請種別と承認ルート（管理者）組織 › ワークフロー
  1. 「種別を追加」をクリックすると「申請種別を追加」ダイアログが開きます。
  2. 基本情報：種別名（必須）・カテゴリ・承認期限（日）を設定します。
  3. 入力項目：「追加」で申請フォームの項目（ラベル・型・必須・選択肢）を定義します。
  4. デフォルト承認ルート：「承認者を追加...」で承認者を順に設定します（契約系は「総務ロールをルート末尾に追加」も可能）。
  5. 「保存」で確定します。既存種別は一覧クリックで編集、ゴミ箱で削除（確認あり）。
CRMマスタ — 商談ステージ・失注理由・タグ（管理者）マスタ › CRMマスタ
  1. 商談ステージ：色を選び「新しいステージ名」を入力して＋で追加（「ステージを追加しました」）。←→で並び替え、鉛筆でラベル編集ができます。受注／失注フラグ付きステージはパイプラインの集計に使われます。
  2. 失注理由／紹介元区分／顧客タグ：それぞれ入力欄＋＋で追加、チップの×で削除します。
ここで編集した選択肢が CRM の記入画面・パイプライン・BI 集計に反映されます。
職人マスタ — 職種・資格の選択肢（管理者）マスタ › 職人マスタ
  1. 職種区分（例：大工）と資格・保有免許（例：施工管理技士）をそれぞれ入力して＋で追加します。
  2. チップにカーソルを合わせると削除できます。ここで登録した選択肢が職人管理（/craftsmen）の登録フォームに表示されます。
Googleカレンダー — 連携・再連携・解除外部連携 › Googleカレンダー
  1. 設定の大タブ「外部連携」、またはユーザーメニューの「外部連携」（/settings?tab=external_integrations）を開きます。
  2. 「Googleカレンダーを連携」または「再連携」で Google 認可します。連携中メールが表示されます。
  3. 「連携を解除」でトークンを削除します。カレンダー画面の予定表示に使います（Gmail 連携はメール画面側）。
アプリ連携 — Chatwork / Slack / LINE WORKS / kintone（管理者）外部連携 › アプリ連携
  1. 連携したいサービスのカードで「連携する」をクリックします。
  2. 必要情報を入力します：Chatwork＝API トークン →「ルームを読み込む」→ 通知ルーム選択、Slack＝Incoming Webhook URL、LINE WORKS＝Client ID / Secret / Bot ID / Channel ID、kintone＝サブドメイン / API トークン / アプリ ID。
  3. 通知するイベント（新規顧客・顧客更新・商談ステージ変更など）にチェックを入れ、「連携を完了」をクリックします。
  4. 連携後は「テスト」で疎通確認、「設定」で変更、「解除」で連携解除ができます。
API / Webhook — 開発者向け連携（管理者）外部連携 › API / Webhook
  1. API キー発行：キー名を入力して「キーを発行」をクリックします。生のキーは発行時に一度だけ表示されるため必ず控えてください。不要になったキーは無効化できます。
  2. Webhook 登録：通知先 URL と対象イベント（カンマ区切り）を入力して「Webhook を登録」をクリックします。署名検証用のシークレットが表示されます。
  3. 配信結果は「Webhook 配信ログ」一覧で確認できます。

Feature Detail

工事台帳（原価管理表）

下請業者ごとに予算・発注・月次請求を管理し、粗利をリアルタイム把握。入力は construction_cost_budgets に永続化されます。

使い方
  1. 工事詳細の「工事台帳」タブを開き、「行を追加」で下請業者の行を追加します（「参照」から見積もり／追加変更の明細を転記することも可能。再参照時は置き換え確認あり）。
  2. 白いセルをクリックして業者名・工種・実行予算・発注額・月次請求を入力します。Enter または別セルへの移動で確定します。
  3. 緑のセル（合計・確定額・予算残・請求残・粗利）は自動計算されます。
  4. 「発注済／未発注」バッジはクリックのたびに切り替わります。行を選択して「選択業者に一括発注」を押すと、追加契約込みの予算合計で発注書ドラフトをまとめて作成できます。単行の「発注」はタブ遷移＋実行予算のみの事前入力です。
  5. 入力内容は自動保存されます（「保存中...」→「自動保存済み」と表示。保存ボタンはありません）。
  6. 「コメント」モードに切り替えるとセル単位でコメントを残せます。
  7. 予算残・請求残がマイナスになると赤字表示されるので、超過にすぐ気付けます。
グループ列種別説明
基本発注ステータス／施工業者／工種／管理用予算入力発注済↔未発注トグル含む
実行予算実行予算／追加契約①②／追加含む実行予算／勘定科目入力＋自動追加含む = 実行＋追加①＋追加②。科目は履歴学習（空行は自動入力しない）

サマリー計算式
実行予算ベース（見込み）工事粗利額 = 契約金額 − 実行予算合計　／　粗利率 = 粗利額 ÷ 契約金額 × 100
確定額ベース（実績）工事粗利額 = 契約金額 − 確定額合計　／　粗利率 = 粗利額 ÷ 契約金額 × 100
