📸 画面スクリーンショット

実際のシステム画面です

ダッシュボード
受注額・パイプライン・顧客数・進行件数などのKPIを一覧表示。勤怠打刻・ワークフロー状況・お知らせをウィジェット形式で確認できます。
勤怠管理
ワンクリックで出退勤打刻。管理者は全スタッフの勤怠を確認・承認でき、月次レポートにも対応しています。
ワークフロー
経費申請・休暇申請・購入申請などを電子化。承認フローを設定し、ステータスをリアルタイムで管理できます。
設定・プロフィール
プロフィール編集・通知設定・会社情報の管理。通知設定はSupabaseに永続保存されます。
アクセス制限ページ
権限のないページにアクセスした場合、このページが表示されます。ロールベースのアクセス制御（RBAC）を実装済みです。
