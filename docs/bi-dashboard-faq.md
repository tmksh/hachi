# BIダッシュボード FAQ（経営確認向け）

確認日: 2026/07/28  
対象画面: `/bi`（BIダッシュボード）

---

## １）粗利額 — 2063万円の下に目標を入れる件

**ご質問**  
2063万円の下に目標を入れるのはいかがでしょうか？売上（実績/目標）3,520万円のところと同じように。

**回答**  
ご提案どおり対応済みです（2026/07/28）。

- KPIラベルを「**粗利（実績/目標）**」に変更
- 売上と同様、実績値の下に期首設定の粗利目標（例: `目標 ¥4,200万`）を表示
- 目標未設定時は「目標 未設定」と表示

**補足**  
表示中の実績粗利は、予備費率が設定されている場合は控除後の値です。目標は期首設定の年間粗利目標をそのまま表示しています。

## ２）月別推移 — 984万・年間粗利2,784万の計算

**ご質問**  
- 損益分岐を超えた分「984万」はどの計算か？
- 年間粗利「2,784万」はどの計算か？予備費等は含まれるか？上段の粗利2,063万と異なる理由は？

**回答**

### 損益分岐を超えた分（984万）

次の式です。

```
984万 ＝ 年間粗利（2,784万）− 製造間接費（1,800万）
```

「いま積み上がった利益（累計）」ではなく、**月別粗利の年間合計**と、期首設定の製造間接費（年額）の差です。  
プラス表示のときは固定費を上回った分、マイナス側のときは固定費に届いていない分を示します。

### 年間粗利（2,784万）と上段粗利（2,063万）の違い

| 項目 | 金額 | 内容 |
|------|------|------|
| 上段「粗利（実績/目標）」 | **2,063万** | 部門別実績粗利の合計（予備費控除後の場合あり） |
| 月別推移「年間粗利」 | **2,784万** | 月別グラフ用データの12ヶ月粗利合計 |

**R8年度（当年度）では、説明用モックデータが使われるため、月別推移の年間粗利はグラフ表示用に実績粗利を約1.35倍した値（2,063 × 1.35 ≒ 2,784）になっています。** 上段KPIとは別系列です。

### 予備費の扱い

- **上段2,063万**: 予備費率が設定されている場合、売上 × 予備費率を粗利から控除した後の値
- **月別2,784万（当年度モック時）**: グラフ用の別計算であり、上段とは連動していません
- 当年度モックでは予備費率0%のため、上段に予備費控除はありません

**補足**  
過去年度を選択するなど、実データ表示時は月別サマリーの年間粗利は上段KPIと同じ `totalGrossProfit`（予備費控除後）になります。

## ３）着地予想 — 契約済6,800万・粗利3,980万・営業利益2,180万の意味

**ご質問**  
契約済みの売上6,800万円、粗利3,980万円、営業利益2,180万円は、契約締結済み案件の積み上げで、請求・入金はまだ、という理解で合っているか？

**回答**  
**デフォルト設定では、その理解は正確ではありません。**

| 表示ラベル | 実際の集計対象（デフォルト） |
|-----------|------------------------------|
| **契約済** | **完工済み工事**（工事ステータス = 完工） |
| **A見込含** | 上記 ＋ 着工前・施工中の工事 ＋ 交渉中〜見積提出中の商談 |

- 着地「契約済」は **契約書テーブル（contracts）の「契約済」ステータス** の積み上げではありません
- **請求書・入金ステータスも見ていません**（請求前／入金前かどうかは区別しません）
- 粗利は主に「受注金額 − 原価（実績原価または予算原価）」で算出

**営業利益2,180万の内訳（表示例）**

```
粗利 3,980万 − 予定配賦（製造間接費）1,800万 ＝ 売上総利益 2,180万
販管費 0  →  営業利益 2,180万
```

**上段の「実績」との違い**

- 上段KPIの実績: **完工工事 ＋ 入金済み請求**
- 着地予想: 年度末までの**見込み積み上げ**（完工・施工中・商談など、設定したソースに依存）

**補足**  
会社ごとに BI 設定（期首設定 → 着地予測パターン）で集計ソースを変更できます。契約書ベースにしたい場合は設定変更が必要です。

**R8年度の数値について**  
売上3,520万・契約済6,800万など、当年度表示は実データではなく**説明用モック**の可能性があります。実データでの確認は過去年度の選択などが必要です。
