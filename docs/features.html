Supabase Auth
メール＋パスワード認証。JWT トークン管理・セッション維持・パスワードリセット対応。RLS でテナント分離。
稼働中
Supabase Database
PostgreSQL をバックエンドとして使用。30+ テーブル・RLS ポリシー・マイグレーション管理。リアルタイムサブスクリプション対応。
稼働中
Supabase Storage
文書管理・クリエイティブ素材のファイル保存。バケット単位で RLS 制御。アップロード・署名付き URL 発行・削除に対応。
稼働中
Gmail API (OAuth 2.0)
Gmail アカウントと OAuth 連携。受信スレッド取得・メール送信・スター管理をシステム内で操作。アカウント接続後は自動同期。
要OAuth設定
Google Calendar API
Google カレンダーと双方向同期。システム内で作成したイベントを Google カレンダーに反映。カレンダー ID を設定で指定。
要OAuth設定

フェーズ2予定
SNS API（予定）
