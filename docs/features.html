BRIDGE AI — 2フェーズ展開
フェーズ1  チャット機能・音声要約・AI 候補日提案でフロント業務を即時支援。   フェーズ2  レイアウト変更・AI 工程表作成・AI 見積もり作成で業務プロセス全体を自動化。
CRM・リード
顧客管理
顧客の登録・編集・検索・削除。法人／個人タブ切替、カード／テーブル表示切替。担当者アサイン、獲得ソース・ステータス記録。顧客詳細から関連する商談・見積・契約・工事を一覧確認できます。タグはマスタ設定＋顧客フォームでの付与に対応。
登録・編集・削除担当者アサイン獲得ソース管理関連データ参照
CRM・リード
商談パイプライン
商談をカンバン形式で管理。ドラッグ&ドロップでステージ変更、DB に即時反映。担当者フィルタ・商談数／総額／受注率の KPI バー表示。「受注」ステージへ移動すると受注確定ダイアログが表示され、見積作成または工事登録へ誘導。商談の追加・編集・削除に対応。
カンバン D&D受注率 KPI受注確定フロー担当者フィルタ
CRM・リード
見積管理
見積書の作成・編集・削除・ステータス管理（下書き／送付済み／受理／却下）。明細行と粗利・粗利率をリアルタイム自動計算。商談からの顧客・金額引き継ぎに対応。工事詳細では1工事に複数見積・版（revision）管理。予備費1（2%）・予備費2（3%）を見積ごとに設定可能。
明細行 CRUD粗利・粗利率計算版管理・改訂予備費設定
CRM・リード
職人管理
協力業者・職人の登録・編集・削除。専門分野・ランク（A/B/C）・資格を管理。カード／リスト表示切替、専門分野フィルタ。詳細ページで進行中案件数・累計受注額を表示。下請発注と連携して工事への紐付けが可能。
登録・編集・削除専門分野・ランク稼働案件数工事下請連携
工事・生産
契約管理
工事契約の登録・編集・削除・ステータス管理（下書き／締結済み／完了／解除）。顧客・見積との紐付け、契約金額・契約日・着工日・完工日・担当者を管理。契約一覧で金額サマリーを表示。
契約 CRUD見積紐付け工期管理金額サマリー
工事・生産
工事管理
工事の進捗・コスト・担当者を管理。詳細画面は7タブ構成：工程表／見積もり／契約書／追加変更／工事台帳／発注書／請求書。ガントチャート、複数見積の版管理、追加変更（CloudSign B案）、工事台帳の DB 永続化、発注書の支払スケジュール（2/4/6/12回）、締日ベースの月次請求生成に対応。
7タブ構成追加変更・CloudSign工事台帳永続化月次請求生成
工事・生産
追加変更工事
工事詳細「追加変更」タブで設計変更・追加工事を管理。変更前後の明細・差額を記録し、承認ワークフローに対応。CloudSign API 連携（B案：顧客が別途契約）で電子署名送信。API 未設定時は PDF ダウンロードで代替。設定 > 会社情報で API キーを登録。
change_ordersCloudSign B案差額・明細比較承認ステータス
工事・生産
工事台帳（原価管理）
工事詳細「工事台帳」タブで下請業者ごとの実行予算・発注・月次請求を管理。粗利・粗利率をリアルタイム計算。construction_cost_budgets テーブルへ永続化し、保存後もデータを保持。見積明細からの初期行インポートに対応。
DB 永続化粗利自動計算月次請求入力予算残アラート
工事・生産
請求管理
請求書の作成・明細編集・消費税計算・ステータス管理（下書き／送付済み／入金済み／キャンセル）。工事詳細「請求書」タブから単発作成、または会社設定の締日（20日締め／月末締め）に基づく月次請求の一括生成。一覧で入金サマリーを表示。ブラウザ印刷に対応。
締日ベース月次生成明細編集・消費税計算入金サマリーブラウザ印刷
工事・生産
予算管理
年度予算の策定・承認・削除。完了工事データから売上・粗利の実績を自動集計し、計画対実績を達成率で表示。複数年度の比較に対応。予算は承認/下書き戻しのワークフロー付き。
年度予算策定完了工事から実績集計達成率表示承認フロー
ポータル
勤怠管理
アナログ時計 UI でワンクリック出退勤打刻。休暇区分（有給・特休・半日等）の選択に対応。月次一覧で出勤日数・実労働時間・残業時間・承認済日数を集計表示。管理者は全スタッフの勤怠を確認・承認・却下可能。所定時刻・休憩・休暇種別は会社設定で管理。
出退勤打刻休暇区分管理月次集計管理者承認
ポータル
ワークフロー
申請種別（稟議書・経費・休暇・購入など）と承認ルートを設定画面でカスタマイズ可能。申請フォームは種別ごとのカスタムフィールドを動的に表示。多段承認・却下・差戻し・コメント機能あり。ステータスは申請中／承認済み／却下でリアルタイム追跡。
カスタム申請種別多段承認ルート動的フォームコメント機能
ポータル
社内回覧板
お知らせ・社内通達の投稿・編集・削除。緊急フラグ・ピン留め・ロール別配信に対応。閲覧時に自動既読記録、コメント機能あり。キーワード・日付・緊急/ピン留めフィルタで検索可能。未読件数はヘッダーバッジでリアルタイム表示。
緊急・ピン留めロール別配信自動既読管理コメント
ポータル
カレンダー
日／週／月表示で社内予定を管理。イベントの作成・編集・削除に対応。メンバーごとに色分けしてオーバーレイ表示。Google カレンダーと OAuth 連携（設定時）することで双方向同期が可能。未連携時は DB イベントのみ表示。
日・週・月表示メンバー色分けGoogle カレンダー連携双方向同期
ポータル
メール連携
Gmail OAuth / IMAP / 手動フォワードで受信スレッドを同期。スレッド一覧・既読・スター管理、メール送信・返信に対応。メールアカウントは設定画面で接続・切断。未連携時はデモスレッドを表示（接続後に実データへ切替）。
Gmail OAuth 連携受信スレッド同期送信・返信スター管理
ポータル
文書管理
社内文書を Supabase Storage でクラウド管理。顧客・工事に紐付けて集約保管可能。リスト／グリッド表示切替、カテゴリタブでファイルを分類。キーワード検索、アップロード（日本語ファイル名含む）・ダウンロード・削除に対応。
顧客・工事紐付けリスト/グリッド表示カテゴリ管理キーワード検索
システム
BI ダッシュボード
経営 KPI（売上・粗利・営業利益）の目標 vs 実績を円形達成率チャートで表示。P&L ウォーターフォール・月次/四半期/年次推移・部門別 KPI・部門別月次（売上構成比按分）・着地予測（会社設定の tier）に対応。期首設定・分析ルール（A見込等の SaaS 設定）・期中変更履歴（遡及按分）を DB 連携。実績は工事/商談/請求から設定に基づき自動集計（工事紐付き請求の二重計上を防止）。
目標 vs 実績P&L ウォーターフォール着地予測 tier 設定期中変更履歴部門別月次按分
システム
ロールベース権限管理
本部管理者・施工店管理者・社員の3段階ロール（オーナーロール廃止）。Next.js Middleware でルートを保護し、Supabase RLS でデータレベルのアクセス制御を二重実施。マーケティングは v2 非公開（全ロールアクセス不可）。メニュー表示・ページアクセス・データ閲覧がロールごとに自動制限される。
3段階ロールRLS + Middleware 二重制御ルート保護CloudSign 設定
システム
通知・設定
未読のお知らせ・承認待ちワークフローをヘッダーのベルバッジで通知（60秒間隔更新）。設定タブはプロフィール・会社情報（CloudSign 連携・請求締日含む）・メンバー招待・パスワード変更・通知 ON/OFF・メール署名・勤怠設定・ワークフロー種別・CRM／職人マスタの管理を提供。
未読バッジ通知CloudSign 設定請求締日設定各種マスタ管理

CloudSign API（B案）
追加変更工事の電子署名連携。設定 > 会社情報で API キーを有効化。顧客が別途 CloudSign を契約する B案。API 未設定時は PDF ダウンロードで代替。change_orders に document_id / status を記録。
追加変更連携B案（顧客契約）PDF 代替
外部連携
Supabase Auth
メール＋パスワード認証。JWT トークンを Cookie に保存してセッション維持。パスワードリセット対応。Supabase RLS と連携してテナント（会社）ごとにデータを完全分離。
JWT 認証セッション管理テナント分離
外部連携
Supabase Database
PostgreSQL 15 をバックエンドとして使用。30 以上のテーブルに RLS ポリシーを適用し、company_id 単位でマルチテナントを実現。マイグレーション管理・リアルタイムサブスクリプションに対応。
PostgreSQL 15RLS ポリシーリアルタイム同期
外部連携
Supabase Storage
文書管理のファイルを Supabase Storage に保存。バケット単位で RLS 制御し、会社ごとにファイルを分離。アップロード・署名付き URL 発行・削除に対応。日本語ファイル名はサニタイズ処理して保存。
クラウドストレージRLS バケット制御署名付き URL
外部連携
Gmail API（OAuth 2.0）
Gmail アカウントと OAuth 連携。受信スレッドの取得・既読管理・スター・メール送信をシステム内で操作。設定画面でアカウント接続・切断・IMAP 設定が可能。calendar.readonly スコープの Google 審査（2〜6週間）が連携の前提。
Gmail OAuth受信スレッド取得メール送信要 OAuth 設定
外部連携
Google Calendar API
Google カレンダーと双方向同期。システム内で作成・編集したイベントを Google カレンダーへ反映。カレンダー ID は設定で指定。OAuth 未接続時は DB イベントのみ表示。Google の OAuth アプリ審査（calendar.readonly は機密スコープ）が必要。
双方向同期カレンダー ID 設定要 OAuth 審査
外部連携
アプリ連携（Chatwork / Slack 等）
設定 → アプリ連携 から 8 種類のツールをボタン操作で接続。API トークンまたは Webhook URL を入力するだけで、顧客・商談・見積・契約・工事・請求・ワークフロー・回覧板の更新を自動通知。連携テスト送信・通知イベントの選択・解除に対応。
ChatworkSlackkintoneテスト通知
外部連携
外部向け REST API
BRIDGE のデータを外部システムから取得するための REST API 窓口。Bearer トークン認証で会社単位にアクセスを制御。案件・工事・見積・請求書・CRM などの主要リソースを JSON で返すエンドポイントを提供。kintone・Salesforce など既存システムとのデータ同期を想定した設計。詳細は API 仕様書 を参照。
REST APIBearer 認証JSONkintone 連携想定

AI 候補日提案（スケジューリング）
顧客詳細「スケジューリング」タブで面談区分（対面／オンライン／電話等）・希望時間帯（午前／午後／夜／いつでも）・所要時間（15〜120分）を選択し、候補日提案ボタンを押すと Google カレンダーの空き状況を確認して候補日を一覧表示。AI が移動を伴うかどうかも判断し、最適な複数日を自動提案してカレンダーに反映。
Google カレンダー連携空き時間自動確認候補日一覧提示移動考慮 AI 判断
